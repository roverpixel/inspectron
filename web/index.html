Architectural Comparison: Classical GPT-2 vs. Modern LLaMA

Why the open-source frontier transitioned from the 2019 Radford et al. baseline to the LLaMA / Mistral / Gemma paradigm:

1. Positional Encoding
GPT-2: Absolute Learned Wpos ∈ ℝT × d. Hard context ceiling.
LLaMA: RoPE (Rotary Position Embedding). Multiplies Q, K in 2D pairs by rotation matrices RΘ, m. Preserves relative distance.
2. Normalization
GPT-2: LayerNorm with mean subtraction & standard deviation: ((x − μ) / σ)γ + β.
LLaMA: RMSNorm. Discards μ shift; scales only by root mean square. 15% faster memory kernel.
3. Non-Linear Activation
GPT-2: Standard 2-layer MLP with GELU or ReLU: W2(GELU(W1x)).
LLaMA: SwiGLU Gated Unit: (Swish(xWgate) ⊗ xWup)Wdown. Higher expressivity.
4. Attention Strategy
GPT-2: Multi-Head Attention (MHA). Key and Value caches require h heads per token.
LLaMA: Grouped-Query Attention (GQA). Multiple query heads share one KV head, saving 75% KV-cache VRAM.

How Transformers Detect Grammar

Unlike classical rule engines with regex dictionaries, decoder transformers learn grammar organically:

  • Induction & Syntax Heads: Track long-range dependencies across prepositional phrases (e.g., connecting "dogs" to "run" over "in the park").
  • Surprisal Metric: An ungrammatical token demands high cross-entropy loss, creating an immediate spike on the flowline.
