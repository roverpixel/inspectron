Architectural Comparison: Classical GPT-2 vs. Modern LLaMA

Why the open-source frontier transitioned from the 2019 Radford et al. baseline to the LLaMA / Mistral / Gemma paradigm:

1. Positional Encoding
GPT-2: Absolute Learned $W_{pos} \in \mathbb{R}^{T \times d}$. Hard context ceiling.
LLaMA: RoPE (Rotary Position Embedding). Multiplies $Q, K$ in 2D pairs by rotation matrices $R_{\Theta, m}$. Preserves relative distance.
2. Normalization
GPT-2: LayerNorm with mean subtraction & standard deviation: $\frac{x-\mu}{\sigma} \gamma + \beta$.
LLaMA: RMSNorm. Discards $\mu$ shift; scales only by root mean square. 15% faster memory kernel.
3. Non-Linear Activation
GPT-2: Standard 2-layer MLP with GELU or ReLU: $W_2(\text{GELU}(W_1 x))$.
LLaMA: SwiGLU Gated Unit: $((\text{Swish}(x W_{gate})) \otimes (x W_{up})) W_{down}$. Higher expressivity.
4. Attention Strategy
GPT-2: Multi-Head Attention (MHA). Key and Value caches require $h$ heads per token.
LLaMA: Grouped-Query Attention (GQA). Multiple query heads share one KV head, saving 75% KV-cache VRAM.
